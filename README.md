# COMP8851 Fraud Dataset Investigation

This repository contains reproducible scripts and reports for investigating
fraud-graph datasets used in the COMP8851 project.

## Current scope

The dataset investigation records:

- Nodes, edges and features
- Fraud and normal node counts
- Fraud percentage and imbalance ratio
- Graph structure and relation types
- Static or dynamic status
- Organic or synthetic anomalies
- Global heterophily
- Local heterophily mean, median and standard deviation
- Original train, validation and test splits
- Dataset limitations and compatibility issues

Model-performance comparison is not included at this stage.

## Data availability

Raw datasets are not stored in this repository because of their size,
licensing and redistribution restrictions. Each dataset folder provides its
official paper, source and download links.

## Environment

Python 3.11 is recommended. Dataset-specific dependencies and execution
instructions are documented in each dataset folder.
