# PMP × Elliptic Evidence

Controlled PMP Elliptic benchmark evidence.

The experiment preserves chronological splitting and includes:
- compatibility smoke evidence
- frozen configuration
- chronological nested split
- final runner
- 12 controlled final runs
- ratio summaries
- threshold evidence
- checkpoints
- execution logs
- repository/environment provenance

The very large raw Elliptic dataset CSV files are intentionally excluded
from Git. The SHA256 of the original complete evidence archive is
preserved under archive/.
