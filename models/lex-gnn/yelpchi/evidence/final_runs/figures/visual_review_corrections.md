# Visual-review corrections

The original calculations and plotted values were correct.

Two presentation changes were made after visual inspection:

1. Figures 1 and 2 were changed from three-column landscape layouts
   to two-column portrait-compatible layouts so that labels remain
   readable when inserted at normal Word-report page width.
2. Figure 2 was changed to grouped bar charts with zero baselines.
   This prevents the GPU-memory and parameter-count panels from
   visually exaggerating differences between models.

Figures 3 and 4 required no substantive change.
No numerical result, configuration, prediction or model output was
modified.
